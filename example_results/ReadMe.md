# Example Results

This directory contains representative outputs generated by the long-read local assembly workflow using the **full long-read WGS input datasets**.

These results demonstrate the expected output structure and analysis products from a complete workflow run. The same samples are also included in the reduced test dataset under `test/`, where the input BAMs have been downsampled to reduce the amount of data required to execute the workflow.

Results generated from the downsampled test data are provided separately in `test/test_results/`.

| Directory | Description |
|---|---|
| `differences/` | Assembly-reference differences for paired-contiguous haplotype assemblies |
| `fasta/` | Reconstructed hap1 and hap2 target-region sequences from paired-contiguous assemblies |
| `pipeline_info/` | Nextflow execution information, including the DAG, execution report, timeline, and trace |
| `qc/` | Coverage QC, read statistics, across-group sequence comparisons, and assembly-reference difference comparisons |
| `report/` | Interactive HTML summary of workflow results |
| `summary/` | Combined assembly results and paired-contiguous assembly summary |

## Results

The example results include assemblies generated across multiple samples, datasets, and flanking-region sizes for the human **FCGR2/3** locus.

Only assembly runs in which **both hap1 and hap2 were classified as contiguous** are represented in the final reconstructed FASTA and assembly-reference difference outputs.

For samples represented by multiple datasets, the workflow also compares independently generated assemblies across groups to evaluate sequence similarity and concordance of assembly-reference differences.

## HTML Report

The primary workflow summary is `report/local_assembly_report.html`

The report provides an interactive overview of input QC, assembly outcomes, structural haplotype assignments where applicable, across-group comparisons, and assembly-reference difference concordance.

These files are provided as representative outputs and do not need to be regenerated to inspect the expected workflow results.
