# Test Results

This directory contains representative outputs generated by the long-read local assembly workflow using the downsampled test dataset provided in `test/data/`.

The test dataset uses the same representative samples as the full long-read WGS analysis, with the input data reduced to the FCGR2/3 locus and 2Mb flanking regions.

The corresponding results generated from the full long-read WGS datasets are provided separately in `example_results/`.

| Directory | Description |
|---|---|
| `differences/` | Assembly-reference differences for paired-contiguous haplotype assemblies |
| `fasta/` | Reconstructed hap1 and hap2 target-region sequences from paired-contiguous assemblies |
| `pipeline_info/` | Nextflow execution information, including the DAG, execution report, timeline, and trace |
| `qc/` | Coverage QC, read statistics, across-group sequence comparisons, and assembly-reference difference comparisons |
| `report/` | Interactive HTML summary of the test workflow results |
| `summary/` | Combined assembly results and paired-contiguous assembly summary |

These outputs demonstrate successful execution of the same assembly, evaluation, reconstruction, comparison, and reporting steps used for the full workflow.

Only assembly runs in which **both hap1 and hap2 were classified as contiguous** are included in the final reconstructed FASTA and assembly-reference difference outputs.

Because the test BAMs contain reduced input data, QC and assembly results may differ from those generated using the full long-read WGS datasets.

## HTML Report

The primary test workflow summary is `report/local_assembly_report.html`

The report provides an interactive overview of input QC, assembly outcomes, structural haplotype assignments where applicable, across-group comparisons, and assembly-reference difference concordance.

These results can be compared with `example_results/` to evaluate workflow behavior using the reduced test inputs.
